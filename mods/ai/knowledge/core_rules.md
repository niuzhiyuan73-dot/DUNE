# 基础规则手册

用途：每次请求固定携带，让模型不必从单张卡的效果文本里反推机制。
性质：**只写"怎样结算"，不写"应该怎么打"**。策略判断留给模型。
溯源：全部来自官方简体中文规则书（`docs/pdf/`，已抽文本到 `dump/pdf_txt/`）。
本局是起义（Uprising）规则框架，附基础包补充；两者冲突时以起义为准。

---

## 1. 一局的骨架

- 一局由若干**轮次**组成，每轮依次走 5 个阶段：
  1. **轮次开始**：从冲突牌库顶翻开 1 张冲突；每人从牌库抽 5 张手牌。
  2. **玩家回合**：按顺时针，每人每次执行一个「特使回合」或「揭示回合」。
  3. **战斗阶段**：结算当前冲突。
  4. **造物主阶段**：在造物主图标位置堆香料。
  5. **召回阶段**：收回特使，起始玩家标记传给下家。
- 玩家持续进行特使回合，直到特使派完（或自愿停止），然后进行**一个**揭示回合。
  次数：可用特使数 次特使回合 + 1 次揭示回合（例：3 个特使 = 4 个回合）。
  唯一例外是魁萨茨·哈德拉克：它移动一个已有特使，所以特使为 0 时仍可打出，见第 2 节。
- 进行过揭示回合后，该玩家在本阶段跳过后续所有回合。
- 每轮只翻 1 张冲突，因此「本轮冲突」只有一个。

## 2. 特使回合

- 从手中打出 **1 张**卡牌（正面朝上放在自己面前），用它把领袖牌上的 **1 名特使**派到版图上。
- 目标位置左上角的图标必须与该卡牌上的某个**特使图标**相同；一张牌只能用其中一个图标。
- **不能**派往已被任何特使占据的位置（间谍标记可以例外，见机制：间谍）。
- 派往某位置时，必须**当场**支付该位置标示的费用/满足其需求；付不出就不能去。
- 结算顺序：位置效果 + 该卡「特使效果区」；若该位置属于四大派系之一，**立即** +1 点该派系影响力。
- 打出该牌时**忽略**它的「揭示效果区」。
- 没有特使图标的卡牌，不能在特使回合打出，只能在揭示回合揭示。
- **例外：魁萨茨·哈德拉克**（费用 8 说服，特使图标：贝尼·杰瑟里特）。
  特使效果原文：「**将你在任何区域的任何特使派遣到任何地区（即便是已经有其他特使的地区）**。」
  也就是说它**移动一个你已经派出去的特使**，不消耗可用特使——所以可用特使为 0 时照样能打出，
  相当于本次冲突多出一个特使回合；而且**目标位置可以是被别人占据的**。
  这种时候游戏确认进入展示阶段会提示「你依然可以进行一次特使阶段（受魁萨茨·哈德拉克影响）」，
  确认进入展示就等于放弃这次额外行动。
  （依据：本地化 `card.imperium.kwisatzhaderach.agent`、`prompt.earlyskitreveal.kwisatzhaderach`、
  `log.turn.agent.kwisatz`。）

## 3. 揭示回合

按顺序四步：

1. **揭示**：把手牌中剩余所有牌正面朝上摊开。
2. **执行揭示效果**：可自选顺序执行这些牌的揭示效果；此前特使回合打出的牌不再触发揭示效果。
3. **设置战力**（见下）。
4. **清理**：把本轮打出的所有牌放入弃牌堆。

**设置战力**：
- 冲突区每支军队 = **2** 战力；每只沙虫 = **3** 战力；本回合揭示出的每个剑刃图标 = **1** 战力。
- 冲突区**没有任何战斗单位**时，战力为 0，且**不会**因剑刃图标或其它效果增加。
- 总战力超过 20 时把指示物翻到 +20 面，再记录超出部分。

**获得卡牌（招募点数）**：
- 招募点数（说服）**只能在本轮自己的揭示回合使用**，轮末未用完即作废，不能跨轮保存。
- 可一次买多张，也可合并不同来源的点数；新牌进**弃牌堆**，不是手牌。
- 帝国牌供应区恒为 5 张，一有卡被拿走立即从牌库补位。
- 牌库抽空时，把弃牌堆洗匀作为新牌库。

## 4. 战斗阶段

**顺序**：从持有起始玩家标记的玩家开始，按顺时针。**每名在冲突区域中有战斗单位的玩家**依次选择：
打出自己持有的**1 张或多张战斗密谋牌**，或者**跳过**。

- **跳过不是退出**：「选择跳过的玩家在之后再次轮到自己时依然可以打出战斗密谋牌」。
- **只有所有玩家都连续选择跳过之后，才会开始结算战斗**。所以一个人跳过，后面还可能反打。
- 每次轮到你都是一次独立决定：**打哪张、打几张、还是跳过**，都要按当前战力与名次重新算。
- 若某张牌让某玩家的战斗单位数量变化（或调整了战力），**立即更新战力指示物**；
  若某玩家在冲突区已没有战斗单位，其**战力立即变为 0**。

**结算**（按战力从高到低）：

| 名次 | 获得 |
|---|---|
| 战力最多 | 冲突胜利，拿冲突牌顶部奖励，并**拿取该冲突牌** |
| 第二名 | 第二栏奖励 |
| 第三名 | **仅 4 人或 6 人游戏**才给第三栏；3 人及以下的游戏里第三栏给"第二名平局者" |
| 战力为 0 | **不获得任何奖励** |

- 拿到冲突牌后立即检查**作战图标**：个人供应区里有**一对相同**的作战图标（晶牙匕／沙鼠／扑翼机）时，
  翻面这两张牌并**获得 1 胜利点**。
- **沙虫翻倍**：获得冲突奖励时，若该玩家在此次冲突中部署了沙虫，奖励**翻倍**
  （多数奖励可加倍，**不含**控制版图位置与冲突牌上的作战图标；含付费的奖励可选择付双倍费用换双倍奖励）。
- 结算后：冲突区军队回**个人供应区**（不是兵营），战力归零，沙虫回公共供应区。

**平局（容易答错，务必按下表）**：

| 情形 | 结果 |
|---|---|
| 多人并列**第一** | 无人获胜、无人拿冲突牌；**所有并列者都拿第二栏奖励** |
| 3 人及以下游戏，并列第一 | 其余玩家**不获得**任何奖励 |
| 4/6 人游戏，仅 2 人并列第一 | 其余玩家仍可争夺第三栏 |
| 4/6 人游戏，3 人并列第一 | 其余玩家不获得任何奖励 |
| 多人并列**第二** | 这些人都拿第三栏奖励 |
| 多人并列**第三** | 都不获得奖励 |

## 5. 造物主阶段与召回阶段

- **造物主阶段**：查看三个带造物主图标的位置（沙漠腹地、哈戈盆地、帝国盆地）。某位置**没有特使**时，从公共供应区放 1 个香料到该位置的造物主图标上；已有香料则叠放。
- **召回阶段**：所有玩家收回全部可用特使放回领袖牌；起始玩家标记传给顺时针下一位。

## 6. 影响力、同盟、控制标记

- 某派系影响力达到 **2 点**，立即获得 **1 胜利点**；若之后跌回 1 点，**失去**该胜利点。
- **同盟**：影响力最高且达标者取得该派系同盟标记并获得标记上的胜利点；被他人超越时标记与胜利点一并转移。
- **控制标记**：赢得"某地点之战"类冲突后，把控制标记放到该位置下方的旗帜位。
  此后**只要有玩家（包括控制者自己）把特使放到该位置**，就由**控制者**获得旗帜奖励——
  奖励归控制者，不归派特使的人。派特使的人只结算该位置自身的图标/效果。
  （原文：「当玩家…放有自己的控制标记时，就会在任何玩家（包括自己）的特使被放在该位置时获得…奖励」。）
- **防御奖励**：当一张对应"已被控制位置"的冲突牌被翻开时，控制该位置的玩家可立即从供应区拿 1 支军队放入冲突区。

## 7. 密谋牌（三类，时机不同）

| 类别 | 可打出的时机 |
|---|---|
| 阴谋 | 自己的特使回合或揭示回合中**任意时刻** |
| 战斗 | **仅战斗阶段** |
| 终局 | **仅游戏结束阶段** |

- 密谋牌平时正面朝下，与牌库分开放；结算完进密谋弃牌堆。
- 密谋牌上的额外费用/条件必须满足才能打出。

## 8. 游戏结束与破平

- 触发条件：有玩家达到**本局胜利阈值**（规则书默认 10；**本局是 16，见当前玩法**），或冲突牌库被抽空。
- 先结算终局密谋牌，再比较胜利点，最高者获胜。
- 破平顺序：**香料 → 宇宙索（太阳币） → 水 → 军营中军队数量**。

## 9. 资源的基本性质

- 三类资源（水 / 香料 / 宇宙索）**互不通用**，各自用于特定位置费用、卡牌或科技的获取/效果。
- 任何花费都必须在效果发生时**立即支付**；付不出则不能执行该效果。
- 「获得 N 某资源」是收益，不是花费——不要把收益记成成本。

## 10. 阅读卡面时的固定读法

- 白色箭头表示「支付左边 → 获得右边」，**可以选择不支付**，每次打出该类卡只能执行 1 次箭头效果。
- 卡牌分「特使效果区」与「揭示效果区」，同一张牌一次只能执行其中一个区域。
- 「选择两个：A/B/C/D」表示**从列出的选项中选 2 个**，不是全部生效。
- 「每场游戏限一次」类效果不占用特使、不占行动，除非文本另有说明。
