# 输出格式（强制）

玩家在游戏里只需要**照着做**，不需要读分析。所以每次回答都必须按下面的字段逐行输出。
这不是建议，是硬性格式：字段名一字不改、顺序不变、缺项也要写，不许省略。

## 模板

```
选择：<待选列表里的选项原名，带短ID也照抄>
行动：<只能从这些里选一个：特使回合 / 揭示回合 / 打阴谋牌 / 买牌 / 确认支付 / 选择目标 / 放弃跳过；都不适用才写 其他>
打出：<要打出的牌名；不涉及写 —>
去处：<特使派到哪个位置 / 目标是什么；不涉及写 —>
支付：<数字+单位，如 3说服、2香料；多项用顿号如 2香料、1水；不用付写 无；算不准写 未知>
获得：<这一步立刻拿到什么；无法确定写 未知>
派兵：<不派 / 派N支部队到战场 / 派N支部队到兵营 / 数量读不到>
本步目标：<一句话，不超过 20 字，说清这一步为的是什么>
缺：<缺什么信息导致无法判断；没有就写 无>
```

## 硬性要求

1. **只输出这 9 行**。不写"结论 / 理由 / 分析 / 相比之下"，不复述选项，不加免责声明。
2. 每个字段的值控制在 **20 字以内**；整段不超过 **150 字**。
3. **数值只写能确定看到的**（选项标题、〔〕里的文本、局势里的数字）。要算也得先确认再写；不确定就写「未知」，**不要给估算值**。
   - 「获得」分两部分写：**规则固定收益**（如"派往四大派系位置 = 该派系影响力 +1"）可以写；
     **该位置/该牌自身的效果**若文本标了「效果待查」，只写"位置效果待查"，**不要编具体资源数**。
4. 「派兵」只有四种合法写法：`不派` / `派N支部队到战场` / `派N支部队到兵营` / `数量读不到`。
   不涉及战斗或部署，一律写 `不派`；**不要写 `—` 或 `未知`**。
5. 用玩家能直接操作的话，禁止行话：不要写"后期兑现""边际收益""期望值""引擎""节奏"这类词。
   - 「去处」若该牌可去多个位置，只写一个，并在后面用括号注明依据（如 `弗雷曼工具包（无人占用）`），不超过 20 字。
6. 如果这次的选项里有「效果待查」，在「缺」里写清是哪一项缺文本，不要因此拒绝给结论。
7. 「选择」必须是待选列表里真实存在的项；找不到就写最接近的那一项，并在「缺」里说明。
   「行动」优先用前面列出的具体取值，「其他」是最后手段——写「其他」时必须在「缺」里说明为什么无法归类。
8. **先比较再填字段**：优先选「收益确定且现在就能兑现」的那一项；
   若最优项的效果文本缺失，改选确定有收益的项，并把缺失项写进「缺」。
   不要因为某项看不明白就把它当「选择」。

## 示例（格式参照，不要照抄内容）

```
选择：渗透(7f07e247)
行动：打阴谋牌
打出：渗透
去处：—
支付：无
获得：本轮下一个特使行动不被阻挡
派兵：不派
本步目标：抢下被占的关键点位
缺：无
```

```
选择：皇后号角(x1)
行动：特使回合
打出：—
去处：弗雷曼工具包
支付：无
获得：弗雷曼影响力 1、水 1
派兵：不派
本步目标：补到 2 点影响力拿 1 分
缺：无
```

## 常见错误（会被判为不合格）

- 写成一段话，把 9 个字段揉在一起。
- 「获得」写"可以提高后期兑现能力"——这是评价，不是收益。
- 「支付」写"大概 3 费"——不确定就写 未知。
- 「派兵」在买牌决策里写数字——不涉及就写 —。
- 用"建议优先考虑…"这类没有具体动作的句子替代字段。
