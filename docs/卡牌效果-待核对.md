# 由游戏能力实体还原的卡牌效果（待核对）

共 26 条。链路：存档 Abilities 子树 → 能力类名 → button 图标序列 → 中文。

## 判据（这一版新增）

1. **图标序列优先**，且只认原名——不剥后缀回退，否则「展示」会拿到「特使」的效果；
2. **基础名文案（XxxAbility）的归属**：只有当同名兄弟里有一条已被图标覆盖时，才把剩下那条文字归给另一方；
3. **纯选择提示一律丢弃**：以「选择」开头、24 字内、且不含「来/以/获得/或/并/→」的，视为交互提示。
   例：「选择一个失去2点影响力的阵营。」= 展示流程里选阵营的那一步，不是效果本身。
