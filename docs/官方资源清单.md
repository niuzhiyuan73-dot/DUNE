# 官方资源清单（可下载）

来源：Dire Wolf Digital 官方资源页 <https://www.direwolfdigital.com/dune-imperium/resources/>

## 一、一键下载（项目根目录执行）

for f in \

 "SCN_DUNE_IMPERIUM_Rulebook_24-10-22.pdf" \
 "SCN_DUNE_IMPERIUM_UPRISING_Rulebook.pdf" \
 "SCN_DUNE_IMPERIUM_UPRISING_Rules_Supplements.pdf" \
 "SCN_DUNE_IMPERIUM_RISE_OF_IX_Rulebook_24-10-22.pdf" \
 "SCN_DUNE_IMPERIUM_IMMORTALITY_Rulebook.pdf" \
 "SCN_DUNE_IMPERIUM_BLOODLINES_Rulebook_v5.pdf" \
 "DUNE_IMPERIUM_FAQ_25-1-13.pdf" \
 "JP_DUNE_IMPERIUM_Card_Errata_22-5-27.pdf" \

  curl -sL -o "docs/pdf/$f" "https://d19y2ttatozxjp.cloudfront.net/pdfs/$f"

`docs/pdf/` 已在 `.gitignore`（约 61 MB，不入库）。

## 三、官方**没有**的东西（重要）

- **没有卡牌列表 PDF**。103 个文件里没有任何 `card list` / `card database` 类文档，
  即无法从官方渠道一次性拿到 300+ 张卡的费用与效果文本。
- 卡牌效果在数字版里是「图标 + 能力实体」运行时拼出来的，本地化里 314 组卡牌有 106 组只有标题。

补卡牌效果只能走：
1. 游戏内能力实体（`worm.canis.abilities.*`，380 条中 338 条有官方中文）——见 `ai_probe/CardDiag.cs`；
2. 第三方卡库（dunecardshub 有 624 张卡索引，但效果文本是 JS 渲染，服务端抓不到）。

## 四、提取方式

```bash
python mods/tools/parse_space_sheets.py   # 规则书 → dump/pdf_txt/spaces_pdf.tsv
```

脚本只取「版图位置速查表」所在的两份规则书，排除不朽/Ix（它们没有速查表，
散落说明里数字是图形、文本层缺失，会产出残缺条目）。

已知 PDF 排版坑：
- `Spice Reﬁ nery` 用的是 `ﬁ` 连字（U+FB01），不是 ASCII，正则 `[A-Za-z]` 会把它挡在外面；
- 标题可能被拆成两行（`最高委员会` / `（High Council）`），不合并会把标题吞进上一条的效果里。
