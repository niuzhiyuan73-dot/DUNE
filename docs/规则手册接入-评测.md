# 规则手册接入 · 评测记录

日期：2026-11-01
目的：验证「把规则讲清楚」是否真的降低**规则性错误**，而不只是让回答更像专家。

---

## 一、做法

四层上下文的实现状态：

| 层 | 文件 | 状态 |
|---|---|---|
| 基础规则 | `mods/ai/knowledge/core_rules.md` | 已接入，每次固定 |
| 当前玩法 | `mods/ai/knowledge/current_mode.md` | 已接入，每次固定 |
| 相关规则（按需） | `mods/ai/knowledge/mechanics.tsv`（17 条机制） | 已接入，命中才带，最多 3 条 |
| 本局记忆 | —— | **未做**，见第五节 |

提示词分层：

```
[system] 角色 + core_rules + current_mode + examples.tsv    ← 稳定前缀（利于上下文缓存）
[user]   局势 → 命中的机制 → 待选列表                        ← 每次变化
```

系统提示从 **361 字** 增至 **约 5.4k 字**（约 3.5k tokens），单次请求成本上升约一个数量级，
但因 30 次/局的配额，单局输入约 10 万 token，成本仍在分角量级。

## 二、题集

`mods/ai/eval/cases.json`，8 道，两类来源：

- **真实日志**：`seq=15`（宣传策略四选二被读成四家全加）、`seq=23`（家族原子只显示「移除并替换公共牌池？」）。
- **构造探针**：私人军团费用、为了全人类特使效果、并列第一的奖励、胜利阈值 16、招募点数是否跨轮、无畏舰控制是否永久。

判分：`must_not` 一条都不能命中；`must_any` 若给出则至少要命中一条（纯描述题留空）。
判据带**否定语境守卫**——「不会永久控制」不算踩雷「永久控制」。

## 三、结果

同一批题、同一份用户消息，只换系统提示，每题跑 3 次（temperature 0.2）：

| 题 | 基线（仅角色提示） | 接入规则后 |
|---|---|---|
| 宣传策略四选二 | 3/3 | 3/3 |
| 家族原子武器 | 3/3 | 3/3 |
| 私人军团费用 | **0/3** | 3/3 |
| 为了全人类特使效果 | 3/3 | 3/3 |
| 并列第一的奖励 | **2/3** | 3/3 |
| 胜利阈值 16 | **0/3** | 3/3 |
| 招募点数跨轮 | 3/3 | 3/3 |
| 无畏舰控制时效 | **1/3** | 3/3 |
| **合计** | **14/24（58%）** | **24/24（100%）** |

多次重跑（判据微调期间）：基线稳定落在 **50%–62%**，接入后 **92%–100%**。

典型失败样本（基线，无畏舰题）：

> 结论：选择「保留无畏舰并取得帝国盆地控制权」……控制帝国盆地还能在后续冲突/结算中持续兑现。
> 无畏舰本身是战场资产，保留它比现在消耗掉更有利于后期继续争夺高价值冲突。

——把"临时控制"当成永久据点，属于纯规则错误，与策略水平无关。

## 四、结论与局限

**结论**：规则层的接入对"规则性错误"有明确效果，尤其是**费用/阈值/时效**这类硬事实。
这几类恰好是先前人工复核卡牌数据时反复出问题的地方，说明它们靠单卡文本补不上，只能靠背景规则。

**局限（不要过度解读）**：

1. 题量 8 道、单模型、单日，缺乏统计效力；只能说明方向，不能给出精确提升幅度。
2. 判分是关键词式的，只能识别"说了错话"，识别不了"理由错但结论对"。
3. 四道构造题的用户消息是我手写的，比真实协议输出更干净；真实场景中噪声更多，效果可能打折。
4. 未测**策略质量**：本评测只回答"它是否理解规则"，不回答"它的建议是否更优"。

## 五、下一步（按优先级）

1. **本局记忆**（第四层）：当前只记录建议、不记录实际发生的事，所以必须先有"事件流"才能做记忆。
   最低可行版本：从 `State` 快照差分出「我方 VP/手牌/影响力/特使占位」的变化，按对局 + 玩家隔离。
2. **一致率度量**：记录模型建议与 AI 实际选择的一致率——这是唯一能回答"建议有没有用"的指标。
3. 题集扩充到 30 道，并加入「同一题两种表述」验证稳定性。
